# 실행 형태

## Decisions

- 이 도구는 사용자가 CGV 페이지에서 직접 실행하는 북마클릿으로 배포한다.
- 소스는 이 저장소에서 관리하고, 빌드 결과인 `javascript:` 한 줄을 사용자가 북마크에 붙여 넣는다.

## Boundaries

- 감시는 사용자가 CGV 탭에서 북마크를 누른 뒤부터 그 페이지가 살아 있는 동안만 돈다. 새로고침이나 페이지 이동은 감시를 끝낸다.
- 자동화 감지를 피하는 조작을 하지 않는다. CGV가 막으면 그 사실을 드러내고 멈춘다.

## Why

CGV는 회차·잔여석과 좌석 배치 조회를 자기 페이지에서 온 요청만 받는다. 사용자의 진짜 브라우저에서 진짜 페이지가 살아 있는 상태여야 한다.

그 조건을 만족시킬 수 있는 방법을 2026년 8월 27일에 차례로 확인했다.

| 방법 | 결과 |
| --- | --- |
| 서버(Node)에서 조회 | 403. 첫 시도부터 거부 |
| 웹앱 브라우저에서 직접 조회 | CORS 차단 |
| Playwright로 띄운 브라우저 | CGV 메인부터 차단 페이지. 자동화 브라우저가 감지된다 |
| 브라우저 확장 | 조건은 만족하지만 회사 보안 정책으로 설치할 수 없다 |
| 북마클릿 | 가능. 사용자가 직접 실행하므로 자동화가 아니다 |

북마클릿은 남은 유일한 길이면서, 사용자의 평소 브라우징과 구분되지 않는 방식이기도 하다. 확장보다 제약이 크지만 지금 환경에서 실제로 동작한다.

`cgv.co.kr`은 CSP 헤더를 보내지 않으므로 북마클릿이 페이지에서 코드를 실행하는 데 제약이 없다.

## Reconsider when

- 확장을 설치할 수 있는 환경으로 옮길 때. 확장이면 페이지 새로고침에 감시가 끊기지 않고, 백그라운드 감시 가능성도 열린다.
- CGV가 CSP를 도입하거나 북마클릿 실행을 막을 때.

## Still-rejected alternatives

- 브라우저 확장 — 실행 조건은 가장 좋으나 회사 보안 정책이 설치를 막는다; 정책 밖 환경으로 옮기면 다시 본다.
- Playwright 등으로 브라우저를 띄워 자동 감시 — CGV가 자동화 브라우저를 감지해 메인 페이지부터 차단한다. 감지를 피하는 것은 우회이므로 하지 않는다.
- 서버에서 조회 — CGV가 403으로 거부한다.

## Evidence worth preserving

- Playwright(headless)로 `https://cgv.co.kr` 접속 시 본문이 "비정상적으로 CGV에 접속한 것이 확인되어 이용이 제한되었어요"이고, 페이지 안에서 회차 조회를 시도해도 403이다.
- `https://cgv.co.kr/` 응답에 `Content-Security-Policy` 헤더가 없다.
- 좌석 조회가 실제로 되는 조건과 응답 구조는 [CGV 데이터 출처](./cgv-data-source.md)에 있다.
